
# Quant Research Lab

A Python-based quantitative finance research portfolio covering risk modeling, derivatives pricing, volatility forecasting, and factor backtesting.

## Modules

###  Risk Engine
- Rolling volatility
- VaR / CVaR
- Stress testing

###  Option Lab
- Black-Scholes pricing
- Greeks
- Implied volatility solver

###  Volatility Forecast
- EWMA
- GARCH
- Rolling out-of-sample evaluation

### Factor Lab
- Momentum factor
- Long-short backtest
- IC evaluation

---

This repository demonstrates quantitative modeling, numerical methods, and financial analytics implemented from scratch in Python.
